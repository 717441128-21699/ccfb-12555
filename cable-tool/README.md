# 电缆绞线结构设计与三维查看工具

给工艺科用的同心绞线结构设计工具:填导体截面、单丝直径、层数,自动排层、算节距比 /
绞入率 / 填充系数,并生成三维绞线模型,可剖切任意截面查看排列,支持紧压扇形单丝。

## 启动

```
node serve.mjs 8123
```

然后浏览器打开 http://localhost:8123 (或直接双击 `start.bat`)。
全部资源本地化(three.js 已内置于 vendor/),工厂内网离线可用。

## 功能

- **自动排层**:按 1+6+12+18+… 正规同心绞分配根数;最外层排不满给黄色"排不满"
  提示,层数不够、根数排不下直接红色报错并给出容量
- **工艺参数**:逐层节距比(可单独改)、节距、绞入率、平均绞入率、截面填充系数、
  外径、单位重量(铜/铝/铝合金)
- **绞向规则**:相邻层自动反向,最外层可选左向(S)/右向(Z)
- **三维视图**:每根单丝按真实螺旋线生成,逐层 InstancedMesh 实例化(千根级
  约 37 个绘制调用),拖拽旋转、滚轮缩放,左上角实时帧率;可开剖切平面看内部
- **截面剖视**:任意轴向位置 z 的横截面,随 z 滑动各层按各自节距/绞向旋转
- **紧压绞**:单丝截面按扇形(圆环扇形)绘制,二维截面和三维扫掠体都是扇形
- **绞入率校核**:精确式 λ=√(1+(πD/h)²) 与螺旋线数值积分对照,偏差约 1e-10 %,
  远低于 0.1% 的要求;同时给出手算近似式 1+(π/m)²/2 的对照值
- **结果复制**:一键把分层参数表复制到剪贴板,直接贴进 Excel / 工艺卡
- **配置分享**:URL 参数可预置输入,如
  `?area=400&wireDia=2.25&layers=4&mode=compact&tab=2d`

## 计算口径

| 项目 | 公式 |
|---|---|
| 层 i 节圆半径 | r = i·d·κ(κ 紧压系数,圆线绞 κ=1) |
| 层容量 | 6i 根;几何上限 ⌊π / arcsin(1/2i)⌋ |
| 节距 | h = m·D(D 为节圆直径或层外径,可选基准) |
| 绞入率 | λ = √(1+(πD节/h)²),手算近似 1+(π/m)²/2 |
| 填充系数 | N·d² / D外² |
| 单位重量 | 实际截面 × 加权绞入率 × 密度 (kg/km) |
