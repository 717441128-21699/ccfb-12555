# 过程式园林种植与实时漫游系统

面向园林方案汇报的纯前端 3D 系统：用**随机 L-系统**过程式生成枝干、GPU **实例化**渲染上万棵树，
在浏览器里完成树种调参、场地笔刷种植、季节物候模拟、修剪萌发与第一人称实时漫游，
从根本上替代"效果图贴片树一转视角就穿帮"的做法。

## 技术栈

- TypeScript + Three.js（WebGL2 / WebGL1 回退）+ Vite
- 无外部建模资源，所有植物几何全部过程式生成

## 启动

```bash
npm install
npm run dev        # 开发，默认 http://127.0.0.1:5180
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
npm run test:unit  # L-系统 / 骨架 / 修剪萌发单元测试（39 项）
npm run typecheck  # 仅类型检查
```

> 浏览器冒烟测试（需本机 Chrome，驱动系统 Chrome 跑无头验证）：
> 先 `npm run build && npm run preview -- --port 5181`，再 `SMOKE_URL=http://127.0.0.1:5181/ npm run test:smoke`。


## 功能与实现对照

| 需求 | 实现位置 | 做法 |
| --- | --- | --- |
| ① L-系统 + 随机规则，每树种一套参数 | `src/core/lsystem.ts`、`src/core/species.ts` | 加权随机产生式展开字符串，龟图（含 `+ - & ^ [ ]`）解释成枝干骨架；5 个内置树种各自独立参数集，UI 可编辑 |
| ② 叶片实例化、上万棵可跑 | `src/core/forest.ts`、`src/core/materials.ts` | 每片叶一个实例、世界坐标烘焙进实例属性，同树种同 LOD 合并为**单个 draw call**；脏标记每帧统一上传，避免逐树重传 |
| ③ 树冠向光偏长、阴影里枝条稀 | `lsystem.ts`、`site.ts`、`template.ts` | 龟图每步把生长方向朝阳光方向偏转（向光性）；建筑投影区按阳光反方向射线求交判定，自动选用 0.45 密度的稀枝变体，整段侧枝随机剔除 |
| ④ 顶点着色器风吹 | `materials.ts` | 枝干按高度加权的低频摆动；叶片高频颤动 + 低频摆动 + 冠层权重，全部在 vertex shader 完成 |
| ⑤ 春夏秋冬叶色 / 落叶量 | `src/scene/seasons.ts` | 全局 uniform 驱动叶色季节插值与覆盖率，落叶按实例种子确定性裁剪；常绿树冬季保叶，落叶树冬季近秃 |
| ⑥ 场地图刷子种树、疏密可调 | `src/scene/planter.ts` | 地面射线 + 圆形笔刷，半径 / 密度滑杆，密度网格累积阈值出种植点，支持擦除；建筑与道路禁种 |
| ⑦ 修剪、剪口下季萌发侧枝 | `src/scene/prune.ts`、`lsystem.ts` | 射线拾取枝干 `branchId` 定位骨架节点，剪除整棵子树；季节推进时每个剪口萌发 2~3 根、2~3 节向光新梢，最多萌发三轮 |
| ⑧ 3 / 5 / 10 年生长预览 | `forest.ts` `maturityOf` | 按树种生长速度的指数成熟曲线，统一缩放树体与叶尺寸，全场一键切换 |
| 万棵 ≥30 FPS、角落实时帧率 | `src/ui/fps.ts`、`main.ts` | 三级 LOD（全枝全叶 / 减面 + 25% 叶 / 远景十字牌）、迁移预算限速、雾效裁剪；右上角实时 FPS，低于 30 FPS 持续 2 秒自动降渲染分辨率 |

## 渲染架构要点

- **三级 LOD**：`<30m` 全精度（6 边枝干 + 全叶）、`<75m` 简化（4 边枝干 + 25% 叶片）、更远只画程序化噪声 alpha 的十字冠幅牌。
- **叶片双层数据、单层实例化**：WebGL 只有一层实例化，因此把每片叶作为一个实例，
  每棵树占连续实例区间，树的平移 / 旋转 / 缩放直接烘焙进叶片世界坐标，池内用区间交换删除保持紧凑。
- **动态池扩容**：叶片池初始只容纳 32 棵树，按倍数增长，远景树不占近景池内存。
- **修剪树合流**：被修剪的树只保留独立枝干网格，其叶片重新烘焙回共享叶片池，仍只增加极少 draw call。
- **批量与快速清空**：随机造林用抖动网格 + 洗牌（O(n)，可稳定种满 1 万棵）并分帧让出主线程；笔刷近邻查询走 2m 空间哈希；"清空场地"直接整池释放 GPU 资源，避免逐树交换删除。
- **数据上传策略**：所有实例池只置脏标记，每帧渲染前统一 `flush` 一次，杜绝逐树重传 GPU 缓冲。

## 目录结构

```
src/
  core/
    rng.ts        确定性随机数（同种子可复现树形）
    species.ts    5 个树种预设与可编辑参数
    lsystem.ts    随机 L-系统、骨架、密度变体、修剪与萌发
    geometry.ts   枝干 / 叶片 / 远景牌几何
    materials.ts  风、季节、雾的 GLSL 着色器
    template.ts   树种 × 密度变体模板缓存
    forest.ts     实例池、LOD 迁移、修剪树管理
  scene/
    site.ts       场地、建筑、实时阴影、阴影判定、笔刷密度网格
    controls.ts   轨道相机 + 第一人称指针锁漫游
    seasons.ts    季节物候
    planter.ts    笔刷种植 / 擦除 / 分帧随机造林
    prune.ts      修剪射线拾取
    preview.ts    面板内独立预览渲染
  ui/fps.ts       帧率统计与自适应降级
  main.ts         装配与 UI 接线
```

## 操作说明

- **树种参数页**：选树种、拖滑杆实时改形，小窗预览自动旋转（可拖动），"应用到全场树木"后重建场景。
- **场地种植页**：选种植 / 擦除笔刷，在地面拖动；"随机混交林 1 万棵"分帧生成不卡 UI。
- **修剪页**：进入后点任意枝条剪除，再切换季节（或开自动轮播）即可看到剪口萌发。
- **漫游页**：指针锁定后 WASD 移动、Shift 加速、鼠标转向、Esc 退出。
