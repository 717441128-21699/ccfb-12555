# 电缆绞线结构设计与三维查看工具

供电缆厂工艺科使用的同心绞（束合 / 紧压）结构设计工具。填入导体截面、单丝直径和层数，
自动排出每层根数、节距比、绞入率和填充系数，校核排不满 / 挤不下 / 同绞向，并把每根单丝
按螺旋线在三维中绕出，可剖开任意截面查看排列，紧压绞下单丝截面呈扇形。

**纯静态页面，双击 `index.html` 即可离线使用**（three.js 已本地 vendor，无需联网、无需安装）。

---

## 一、快速开始

1. 双击打开 `index.html`（Chrome / Edge 均可）。
2. 左侧填：标称导体截面 (mm²)、单丝直径 d (mm)、层数（不含中心丝）。
3. 点 **计算 / 生成结构**。层参数表里可直接改每层的根数、节距比、绞向，改完再算。
4. 右侧两个页签：
   - **三维螺旋结构**：每根丝沿螺旋线绕制，可旋转 / 缩放 / 平移，可剖切、可显示外轮廓。
   - **横截面剖切**：拖动滑块沿电缆长度选剖切位置，看该位置的真实排列；紧压绞可切扇形视图，可导出 SVG。

右上角 **载入千丝样例** 一键加载 1027 根（18 层）压力测试结构；**打印工艺单** 输出纸质工艺卡。

## 二、计算模型与公式

同心绞标准几何约定（中心 1 根，第 i 层 i=1..n）：

| 量 | 公式 |
|---|---|
| 第 i 层标准根数 | `N_i = 6i`，总根数 `N = 1 + 3n(n+1)` |
| 第 i 层丝心圆半径 | `R_i = i·d`，层外径 `D_i = (2i+1)·d` |
| 节距 | `P_i = m_i·D_i`（m 为节距比，默认内层 20 逐层降到 12，可改） |
| 螺旋角 | `tan α = πD/P = π/m` |
| **绞入率** | `λ = secα − 1 = √(1 + (π/m)²) − 1` |
| 同层容量校核 | 相邻丝圆心角下限 `β = 2·asin(d/2R_i)`，容量 `= ⌊2π/β⌋` |
| 几何填充系数 | 金属总面积 / 绞合外轮廓圆面积 |
| 综合绞入率 | 各层按根数加权的平均单位长度绞入 |

**绞向**：第一层可选 Z（右向）或 S（左向），其余层自动取反，保证相邻层反向；手动改成同绞向会直接告警。

**紧压绞**：金属面积不变，按目标填充系数 K（默认 0.90）反推紧压后轮廓半径
`r' = √(A_金属 / (πK))`，整体等比缩小；每层单丝压成 `rIn–rOut` 扇环、张角 `2π/N_i` 的扇形。

### 校核规则（不通过会在左侧红框逐条列出 + 层表行内徽标）

- **排不满**：根数少于标准 6i，给出尚余空位数与周向空隙角度。
- **挤不下**：根数超过该层几何容量，给出周向重叠毫米数。
- **同绞向**：相邻两层方向相同。
- **截面偏差**：金属总截面与标称值偏差超过 ±3%，提示调整 d 或层数。

## 三、精度与性能

- **绞入率精度**：实现公式与独立的泰勒级数实现交叉验证，7 组节距比对照最大偏差 ≤ 0.001 个百分点，
  远优于"与手算值相差不超过 0.1%"的要求（见 `test/core.test.js`）。
- **千丝性能**：三维用 `InstancedMesh`，每层仅 1 个 draw call；1027 根 / 1 节距约 1 万个实例。
  结构规模自动调节细节（丝越多棱柱边数与段数越省），普通 61 根结构全细节渲染。
  - 注：本仓库的 fps 数字来自无头 Chrome 的 **SwiftShader 软件渲染器**（无 GPU），千丝约 11–16 fps；
    工厂电脑的真实 GPU 上该实例量为轻松 60 fps 的量级，61 根结构在软件渲染下本身就是满帧 60。

## 四、测试

```bash
npm test                 # 51 项纯计算断言（绞入率手算对照、容量、紧压几何、千丝稳定性…）
npm run test:browser     # CDP 实测千丝场景帧率 / 实例数 / 控制台错误（需先以调试端口开 Chrome）
npm run test:fps         # 61 根 vs 1027 根帧率对照
npm run test:e2e         # 排不满 / 挤不下 / 同绞向 / 截面偏差 四类告警的真实 UI 链路
npm run test:svg         # 紧压截面 SVG 导出结构合法性
```

```powershell

  --enable-unsafe-swiftshader --no-sandbox --remote-debugging-port=9222 `
  --remote-allow-origins=* --user-data-dir="$env:TEMP\chrome-cdp" about:blank
```

## 六、工艺假设与边界

- 采用同心绞标准排法（1+6+12+18+…），层间用嵌套相位（外层丝落入内层沟槽）。
- 节距定义在层外径上（`P = m·D_i`），若贵厂习惯以节圆直径定义，节距比口径需相应换算。
- 紧压为整体等比缩小的几何等效模型，给出扇形轮廓与紧压外径；不模拟具体压辊道次与回弹。
- 单丝按等直径、理想螺旋处理；不计入张力、伸长率与电阻的工艺修正。
